permitcheck

The model reads. Code decides. permitcheck checks a synthetic permit application against a fictional city code, cites each section, and sends anything unclear to a person.

A false approve is an application with at least one seeded critical violation that the tool marks as pass on that rule.

# Correction letter: LH-APP-0018

> SYNTHETIC DATA ONLY. Larkspur Hollow and its code are fictional. This tool gives no legal advice. Not for production use.

Dear applicant,

We ran a first-pass check of application LH-APP-0018 against the Larkspur Hollow Residential Code (LHRC) version 2026.1. A software tool wrote this draft. A reviewer reads it before it is sent.

## Please correct these items

1. [R18, LHRC 12.4.2] Footing depth. We read that footing depth is 29 in, and this section requires at least 30 in. The code says: The bottom of each deck footing sits at least 30 in below grade.
2. [R03, LHRC 10.1.3] Who builds. We read that contractor is LHC-288, which is not in the form this section requires. The code says: The application names a contractor with a city license number in the form LHC-00000, or states that the owner builds the work.
3. [R11, LHRC 12.1.1] Deck size for standard review. We read that new area is 1500 sq ft, and this section requires at most 500 sq ft. The code says: A deck reviewed on the standard path has no more than 500 sq ft of floor area. A larger deck needs an engineered review.

## Please confirm these items

We could not read these clearly enough to decide. Please state each value plainly, with units.

1. [R12, LHRC 12.2.1] Guard height. The guard height (guard_height_in) is missing. The code says: When the walking surface of a deck is more than 24 in above grade, a guard runs along each open side and stands at least 38 in tall.
2. [R14, LHRC 12.3.1] Stair riser height. The stair riser (stair_riser_in) was read with low confidence (0.30). The code says: Each stair riser on a deck stair is no taller than 7.5 in.

Thank you,

Larkspur Hollow Building Division (fictional)
